# YandexSpeechKit

Документация по модулю `YandexSpeechKit` разделена на два основных файла:

## Что открывать

Если нужно настроить API-ключ, выбрать голос/интонацию, проверить предпрослушивание и управлять кэшем фраз через админку, начните с [руководства пользователя](USER_GUIDE.ru.md).

Если нужны детали реализации (методы плагина, логика cache key, JSON-действия admin, поведение интервалов `level`), откройте [техническую документацию](TECHNICAL_REFERENCE.ru.md).
