# YandexSpeechKit - Руководство пользователя

![YandexSpeechKit Icon](../static/YandexSpeechKit.png "Плагин YandexSpeechKit")

## Назначение

`YandexSpeechKit` это модуль синтеза речи для osysHome, использующий Yandex Cloud SpeechKit.

Модуль нужен, чтобы:

- синтезировать голос из текста через Yandex TTS API;
- работать в режимах API `v1` и `v3`;
- выбирать голос и интонацию (emotion/role);
- при необходимости задавать громкость по умолчанию (`0..100`) для API `v3`;
- кэшировать сгенерированные MP3 и переиспользовать их;
- управлять кэшем фраз из админ-интерфейса.

> [!IMPORTANT]
> Модуль не только синтезирует речь, но и ведет локальный кэш. Повторные фразы обычно воспроизводятся из кэша без нового вызова API.

---

## Что получает пользователь

| Возможность | Что делает |
| --- | --- |
| Синтез речи | Преобразует текст в MP3 |
| Голосовые профили | Поддерживает разные голоса и интонации |
| Выбор API режима | Позволяет переключать `v1` и `v3` |
| Предпрослушивание | Проигрывает тестовый звук в настройках до сохранения |
| Интервалы уровней | По диапазону `level` можно переопределять эмоцию/громкость или пропускать озвучивание |
| UI кэша фраз | Просмотр, фильтр, прослушивание, скачивание, удаление и предзаполнение кэша |

## Обзор интерфейса

Страница админки:

```text
/admin/YandexSpeechKit
```

На странице две вкладки:

1. `Settings`
2. `Phrase cache`

### Блоки вкладки Settings

- `Connection`: ввод API-ключа.
- `Voice and intonation`: версия API, голос, интонация, громкость по умолчанию, кнопка предпрослушивания.
- `Level intervals`: правила для диапазонов `say(level=...)`.
- `Cache`: сводка и кнопка полной очистки кэша.

### Действия на вкладке Phrase cache

- обновить список кэша;
- очистить весь кэш;
- добавить новую фразу в кэш;
- фильтровать и сортировать по тексту фразы;
- действия по строке: прослушать, скачать, удалить.

## Чек-лист быстрого запуска

- [ ] Откройте `/admin/YandexSpeechKit`.
- [ ] Вставьте API-ключ Yandex Cloud.
- [ ] Выберите `API version` (`v1` или `v3`).
- [ ] Выберите `Voice` и `Intonation`.
- [ ] (Опционально) задайте `Default volume` (`0..100`, актуально для `v3`).
- [ ] Нажмите `Listen` для теста.
- [ ] Сохраните настройки.
- [ ] Вызовите озвучку через `say("...")` в сценарии/скрипте.

---

## Параметры настройки

| Поле | Обязательно | Описание |
| --- | --- | --- |
| `access_key` | Да | API-ключ Yandex Cloud |
| `api_version` | Да | `v1` или `v3` |
| `speaker` | Да | Выбранный голос |
| `emotion` | Да | Выбранная интонация/роль |
| `default_volume` | Нет | `0..100`; для `v3` переводится в LUFS-подсказку |

### Поведение версий API

- `v1` использует endpoint `/speech/v1/tts:synthesize`.
- `v3` использует endpoint `/tts/v3/utteranceSynthesis` и поддерживает подсказку громкости.

> [!NOTE]
> При выборе `v1` в UI показываются только голоса, поддерживаемые v1.

## Поддерживаемые сценарии использования

### Базовая озвучка

```python
from app.core.lib.common import say

say("Система поставлена на охрану")
```

### Переопределение голоса на один вызов

```python
say("Внимание", args={
    "voice": "jane",
    "emotion": "good"
})
```

### Переопределение громкости на один вызов

```python
say("Ночной режим включен", args={
    "volume": 35
})
```

### Полный вызов через функцию плагина

```python
app.callPluginFunction("YandexSpeechKit", "say", {
    "message": "Гараж открыт",
    "level": 2,
    "args": {
        "speaker": "marina",
        "emotion": "friendly",
        "volume": 70
    }
})
```

## Интервалы уровней (правила приоритета)

Можно задать несколько диапазонов уровней с переопределениями:

- диапазон `min`, `max`;
- `skip` (не озвучивать);
- принудительная `emotion`;
- принудительная `volume`.

Пример:

| Min | Max | Skip | Emotion | Volume |
| --- | --- | --- | --- | --- |
| 0 | 2 | Нет | friendly | 80 |
| 3 | 5 | Нет | neutral | 60 |
| 6 | 10 | Да | neutral | - |

Если подходит несколько диапазонов, модуль применяет более узкий (более специфичный) интервал первым.

## Управление кэшем фраз

Модуль хранит MP3-файлы в кэше и метаданные (текст, голос, эмоция, громкость).

Через UI можно:

- добавить фразу в кэш без воспроизведения;
- видеть текст фразы и hash ID;
- прослушивать кэшированный звук;
- скачивать MP3;
- удалять один файл;
- очищать весь кэш.

> [!TIP]
> После смены основного голоса очищайте кэш, чтобы старые фразы были пересинтезированы новым голосом.

## Диагностика и типовые проблемы

### Не работает предпрослушивание

Проверьте:

- заполнен ли API-ключ;
- есть ли доступ в интернет к Yandex TTS endpoints;
- валидны ли выбранные голос/интонация для выбранной версии API.

### Фразы звучат со старыми настройками

Причина: уже есть запись в кэше.

Решение: очистить кэш и синтезировать заново.

### Нет звука при runtime `say(...)`

Проверьте:

- что текст сообщения не пустой;
- что локальная подсистема воспроизведения работает (`playSound`);
- логи на предмет API-ошибок и предупреждений о пустом аудио.
