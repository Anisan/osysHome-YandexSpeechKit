# YandexSpeechKit - Yandex синтез речи

Синтез речи с использованием API Yandex SpeechKit для преобразования текста в речь.

## Описание

Плагин `YandexSpeechKit` предоставляет возможности синтеза речи для платформы osysHome с использованием API Yandex SpeechKit. Он преобразует текстовые сообщения в аудио файлы речи с интеллектуальной системой кэширования для оптимизации использования API и повышения производительности.

## Основные возможности

- ✅ **Синтез речи**: Преобразование текста в высококачественную речь с использованием API Yandex SpeechKit
- ✅ **Множество голосов**: Выбор из множества голосов (API v1 и v3)
- ✅ **Управление эмоциями**: Настройка интонации (нейтральная, шёпот, дружелюбная, радостная и др.)
- ✅ **Переопределение на вызов**: Голос и интонация могут задаваться через `args` для каждого вызова `say`
- ✅ **Умное кэширование**: Автоматическое кэширование сгенерированных аудио файлов с использованием MD5 хэша для предотвращения избыточных вызовов API
- ✅ **Формат MP3**: Генерация аудио в широко поддерживаемом формате MP3
- ✅ **Веб-интерфейс администратора**: Простая настройка через веб-панель администратора

## Панель администратора

Плагин предоставляет удобный административный интерфейс, доступный из панели управления osysHome:

- **Настройка ключа доступа**: Введите ваш API ключ Yandex SpeechKit
- **Выбор голоса**: Выберите из доступных голосов
- **Настройки эмоций**: Выберите желаемую эмоциональную окраску для синтеза речи

## Конфигурация

Настройте следующие параметры через панель администратора:

- **Access Key**: Ваш ключ доступа к API Yandex SpeechKit (обязательно)
  - Получите API ключ в [Консоли Yandex Cloud](https://console.cloud.yandex.com/)
- **Speaker**: Выбор голоса (по умолчанию: `marina`)
- **Emotion**: Эмоциональная окраска речи (по умолчанию: `neutral`)

- alexander (М), anton (М), kirill (М)

## Доступные интонации (эмоции)

Поддерживаемые эмоции зависят от выбранного голоса:
- **neutral** — нейтральная (по умолчанию)
- **good** — радостная
- **evil** — раздражённая
- **friendly** — дружелюбная
- **strict** — строгая
- **whisper** — шёпот

Подробнее о голосах и доступных эмоциях см. в [документации Yandex SpeechKit](https://yandex.cloud/ru/docs/speechkit/tts/voices).

## Использование

### Программное использование

Используйте действие `say` для синтеза и воспроизведения речи:

```python
from app.core.lib.common import say

# Простой вызов (использует голос и интонацию из настроек)
say("Привет, это тест")

# Вызов с изменением голоса и интонации через args
say("Привет! Это радостное сообщение", level=0, args={
    "voice": "marina",
    "emotion": "good"
})

# Альтернатива: callPluginFunction
app.callPluginFunction("YandexSpeechKit", "say", {
    "message": "Привет, это тест",
    "level": 0,
    "args": {
        "voice": "jane",
        "emotion": "friendly"
    }
})
```

**args** (dict) поддерживает:
- `voice` или `speaker` — голос для этого вызова (например `marina`, `jane`, `alexander`)
- `emotion` — интонация (например `neutral`, `good`, `whisper`, `friendly`)

### Как это работает

1. Плагин получает текст для синтеза
2. Создает MD5 хэш текста для кэширования
3. Проверяет наличие кэшированного аудио файла
4. Если файл не закэширован, вызывает API Yandex SpeechKit для синтеза речи
5. Сохраняет аудио файл в кэш
6. Воспроизводит аудио файл

## Технические детали

- **API Endpoint**: `https://tts.api.cloud.yandex.net/speech/v1/tts:synthesize`
- **Аудио формат**: MP3
- **Язык**: Русский (ru-RU)
- **Кэширование**: Система кэширования файлов на основе MD5 хэша
- **Обработка ошибок**: Комплексная обработка исключений с логированием
- **Управление директориями**: Автоматическое создание директорий для кэша

## Действия

Плагин предоставляет следующие действия:

- **say**: Синтез текста в речь и воспроизведение аудио
  - Параметры:
    - `message` (string): Текст для синтеза
    - `level` (int): Уровень громкости (по умолчанию: 0)
    - `args` (dict): Дополнительные аргументы
      - `voice` или `speaker` (str): Голос для этого вызова
      - `emotion` (str): Интонация (neutral, good, whisper, friendly и др.)

## Установка

1. Поместите плагин в директорию `plugins/YandexSpeechKit/`
2. Перезапустите osysHome
3. Настройте плагин через панель администратора
4. Введите ваш API ключ Yandex SpeechKit
5. Выберите предпочитаемый голос и настройки эмоций

## Решение проблем

### Частые проблемы

- **Ошибка API ключа**: Убедитесь, что ваш API ключ действителен и имеет разрешения для SpeechKit
- **Проблемы с сетью**: Проверьте подключение к интернету и статус сервисов Yandex Cloud
- **Проблемы с кэшем**: Плагин автоматически создает директории кэша с правильными разрешениями
- **Пустые аудио файлы**: Проверьте ответ API и доступное место на диске

### Логи

Проверьте логи плагина для получения подробных сообщений об ошибках и отладочной информации.
